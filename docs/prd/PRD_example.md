# Emotion Analyzer Web App - PRD

## 1. 제품 개요
사용자가 입력한 영문 텍스트를 분석하여 감정 상태를 판별하고, 해당 감정에 공감하는 추천 답변을 제공하는 단일 페이지 웹 애플리케이션(SPA)입니다.

---

## 2. 목표 (Goal)
- **감정의 시각적 확인**: 사용자가 입력한 문장의 감정을 점수와 이모지, 테마 컬러로 즉시 확인할 수 있도록 합니다.
- **공감 기반 피드백**: 판별된 감정에 맞춘 동적인 위로 및 공감 답변을 무작위로 추천합니다.
- **사용성 극대화**: 로그인 없이 브라우저 내에서 즉각 실행되는 심플하고 유려한 반응형 UI를 제공합니다.

---

## 3. 핵심 기능 (MVP)

### 기능 1 — 문장 입력 및 검증
- **입력 창**: 넓은 텍스트 입력을 위한 `textarea` 컴포넌트 제공.
- **글자 수 검증**: 
  - 최소 글자 수: 2자 이상
  - 최대 글자 수: 500자 이하
- **안내 메시지**: 영문 입력 전용 서비스임을 명시하는 가이드 텍스트 노출.

---

### 기능 2 — 로컬 감정 분석
- **분석 라이브러리**: 클라이언트 브라우저 단에서 동작하는 `Sentiment.js` 사용.
- **감정 스코어링**: 
  - 분석 점수(Score)를 기반으로 감정을 3가지로 판류:
    - **Positive** (Score > 0): 😊 긍정 상태
    - **Neutral** (Score == 0): 😐 중립 상태
    - **Negative** (Score < 0): 😢 부정 상태
  - 상세 감정 지표인 Sentiment Score와 Comparative Score를 함께 시각화.

---

### 기능 3 — 동적 추천 답변 제공
- 감정 상태에 따라 사전에 정의된 답변 풀(Pool)에서 임의(Random)의 문장을 선택하여 출력합니다.
- **답변 데이터**:
  - **Positive**: 
    - "좋은 하루였나 보네요! 그 기분이 더 오래 가길 바랄게요. 😊"
    - "멋져요! 당신의 긍정적인 에너지가 주변 사람들에게도 전달될 거예요."
    - "즐거운 순간을 기록해주셔서 감사해요. 오늘도 파이팅!"
  - **Neutral**: 
    - "조금 더 이야기해줄래요? 어떤 일들이 있었는지 궁금해요. 😐"
    - "평온한 일상이군요. 가끔은 이런 잔잔한 하루도 좋은 법이죠."
    - "당신의 차분한 하루를 응원합니다."
  - **Negative**: 
    - "많이 힘들었겠어요. 오늘 하루도 정말 고생 많으셨습니다. 😢"
    - "속상한 마음이 느껴지네요. 슬픈 감정을 억누르지 않아도 괜찮아요."
    - "힘든 시간이 지나가고 나면, 꼭 좋은 일이 찾아올 거예요. 힘내세요."

---

### 기능 4 — 세션 분석 기록 (히스토리)
- **로컬 세션 유지**: 사용자가 페이지를 새로고침하기 전까지 최근 수행한 **3개의 분석 기록**을 타임라인 카드로 하단에 유지.
- **기록 항목**: 입력했던 텍스트 일부, 감정 결과, 수행 시간.

---

## 4. 사용자 흐름 (User Flow)
1. 사용자가 웹페이지에 접속하여 입력 가이드를 확인합니다.
2. `textarea`에 영문 문장을 입력합니다 (실시간 글자 수 카운팅 제공).
3. "분석" 버튼을 클릭합니다.
4. 예외 검증(공백 검사, 2자 미만 등) 통과 후 즉시 감정 분석이 작동합니다.
5. 결과 카드(이모지, 테마 컬러, 점수 계기판) 및 추천 답변 영역에 동적 애니메이션 효과와 함께 결과가 출력됩니다.
6. 하단 히스토리 목록에 최근 분석 건이 추가됩니다.

---

## 5. UI/UX 요구사항
- **Header**: 서비스 명 및 깔끔한 설명 문구.
- **Input Area**: `textarea` 입력란, 실시간 글자수 카운터, 분석 버튼.
- **Result Dashboard**:
  - 감정에 따라 변화하는 테마 컬러 배경 (Positive: Emerald / Neutral: Gray / Negative: Crimson/Violet)
  - 감정 이모지 및 큰 텍스트 판별 결과
  - Sentiment Score 계기판
- **Recommendation Area**: 공감 답변 텍스트 박스.
- **History Area**: 하단에 카드 형태로 배치되는 최근 3개 분석 결과.

---

## 6. 비기능 요구사항
- **반응형 웹**: 모바일, 태블릿, 데스크톱 레이아웃에 완벽 대응하는 CSS Flexbox/Grid 설계.
- **성능**: 네트워크 레이턴시가 없는 로컬 클라이언트 처리로 0.5초 이내 결과 렌더링.
- **보안**: 사용자 데이터는 백엔드 서버로 전송되지 않으며 로컬 브라우저 메모리에만 상주.

---

## 7. MVP 제외 범위
- 사용자 로그인 및 인증 기능
- 데이터베이스(DB) 영구 저장 기능
- 실시간 챗봇 또는 AI 대화 기능
- 영어 이외의 다국어 형태소 정밀 분석

---

## 8. 성공 기준
- 사용자가 영문 텍스트를 입력하고 분석 결과를 이모지와 점수로 즉각 확인 가능.
- 감정 분류에 상응하는 동적인 공감 메시지가 중복되지 않고 올바르게 무작위 노출됨.
- 로컬 세션 내 최근 3개 분석 기록이 실시간으로 히스토리에 정상 누적됨.

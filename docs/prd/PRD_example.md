# Emotion Analyzer Web App - PRD

## 1. 제품 개요

사용자가 입력한 문장을 감정 분석하여 감정 상태를 보여주고,
적절한 추천 답변 문장을 제공하는 간단한 웹 서비스.

---

## 2. 목표 (Goal)

- 사용자가 자신의 감정을 쉽게 확인할 수 있도록 한다.
- 공감 기반 추천 답변을 제공한다.
- 누구나 간단히 사용할 수 있는 UI를 제공한다.

---

## 3. 핵심 기능 (MVP)

### 기능 1 — 문장 입력
- 사용자가 텍스트를 입력할 수 있다.
- `textarea` 사용

---

### 기능 2 — 감정 분석
- "분석" 버튼 클릭 시 감정 분석 수행
- Sentiment.js 사용

분석 결과 예시:
- Positive
- Neutral
- Negative

추가 점수:
- sentiment score 표시

---

### 기능 3 — 추천 답변 제공
감정 결과에 따라 추천 문장 출력

예시:
- Positive
  - "좋은 하루였나 보네요!"
- Negative
  - "많이 힘들었겠어요."
- Neutral
  - "조금 더 이야기해줄래요?"

---

## 4. 사용자 흐름

1. 사용자가 웹페이지 접속
2. 문장 입력
3. "분석" 버튼 클릭
4. 감정 분석 실행
5. 결과 출력
6. 추천 답변 출력

---

## 5. UI 요구사항

### 필수 UI
- 제목(Header)
- 텍스트 입력창
- 분석 버튼
- 분석 결과 영역
- 추천 답변 영역

---

## 6. 비기능 요구사항

- 모바일 대응 반응형 UI
- 3초 이내 결과 출력
- 별도 회원가입 없음
- 무료 배포 가능해야 함

---

## 7. MVP 범위 제외

아래 기능은 MVP 제외:
- 로그인
- DB 저장
- 채팅 기능
- AI 대화 기능
- 음성 입력
- 다국어 지원

---

## 8. 성공 기준

- 사용자가 문장을 입력하고 결과를 확인 가능
- 감정 결과와 추천 답변 정상 출력
- 무료 배포 완료

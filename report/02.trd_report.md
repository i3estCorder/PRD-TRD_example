## 🛠️ 아키텍처 및 기술 결정 사항
- **프론트엔드 구성**: 순수 HTML/CSS/JavaScript로 가볍고 신속하게 동작하도록 설계 (No Framework).
- **감정 분석 엔진**: CDN을 통해 클라이언트 브라우저 단에서 직접 실행되는 `Sentiment.js` 라이브러리 사용.
- **배포 인프라**: GitHub 저장소 연동을 통한 Vercel 자동 배포(Serverless/Static hosting).

## ⚡ 기술적 위험 요소 (Risk Analysis) & 대책
1. **외부 API 의존성 배제**:
   - 백엔드 서버나 외부 LLM API 호출이 없으므로 네트워크 지연이나 API 비용 리스크가 전혀 없음 (완전한 로컬 클라이언트 처리).
2. **Sentiment.js 라이브러리 로딩 지연 가능성**:
   - CDN 장애를 대비해 HTML 헤더에서 비동기(`defer`/`async`)로 라이브러리를 로드하고, 로딩 완료 전 버튼을 비활성화하는 안전장치 도입.

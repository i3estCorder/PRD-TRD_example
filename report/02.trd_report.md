## 🛠️ 아키텍처 및 기술 결정 사항

### 1. LocalStorage 기반 영구 데이터 보존
- 새로고침 시 데이터 소실 단점을 해결하기 위해 브라우저 `LocalStorage`를 활용해 최근 3건 분석 히스토리를 세션에 영구 보존하는 아키텍처로 변경 확정하였습니다.

### 2. Sentiment.js CDN 로딩 제어
- `https://cdn.jsdelivr.net/npm/sentiment@5.0.2/lib/index.min.js`를 사용하며, 로딩 실패 시 UI가 붕괴되지 않고 사용자에게 로딩 중/실패 경고를 친절히 표시하도록 예외 처리를 반영하였습니다.

### 3. 반응형 다크 모드 글래스모피즘
- 디자인적 완성도를 위해 최신 CSS3 커스텀 프로퍼티와 블러 필터(`backdrop-filter: blur(10px)`)를 이용한 프리미엄 글래스모피즘 컴포넌트 설계를 적용하였습니다.

## ⚡ 기술적 위험 요소 (Risk Analysis) & 대책
1. **네트워크 단절로 인한 CDN 로드 실패**:
   - 자바스크립트 내 `typeof Sentiment === 'undefined'` 조건을 검사하여 분석 버튼을 비활성화하고, 안전하게 재시도를 안내하는 에러 바운더리 로직을 `script.js`에 배치합니다.
2. **LocalStorage 용량 한계 및 오버플로우**:
   - 저장 데이터는 최대 3건으로 엄격히 제한하므로 용량 초과 이슈가 원천 차단됩니다.

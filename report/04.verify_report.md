|---|---|---|---|---|
| TC-01 | **긍정 문장 입력 테스트**<br>(예: "Today is a wonderful day! I am extremely happy.") | Sentiment score > 0 및 "Positive" 판별 및 긍정 메시지 출력, 녹색 테마 전환 | **PASS** | 스코어 +5 판별, 랜덤 공감 답변 노출 및 에메랄드 테마 정상 작동 |
| TC-02 | **부정 문장 입력 테스트**<br>(예: "I feel so lonely and sad today. Everything is going wrong.") | Sentiment score < 0 및 "Negative" 판별 및 위로 메시지 출력, 빨간색 테마 전환 | **PASS** | 스코어 -4 판별, 랜덤 공감 답변 노출 및 로즈 테마 정상 작동 |
| TC-03 | **중립 문장 입력 테스트**<br>(예: "The book is on the table next to the window.") | Sentiment score = 0 및 "Neutral" 판별 및 중립 메시지 출력, 회색 테마 전환 | **PASS** | 스코어 0 판별, 중립형 답변 노출 및 슬레이트 테마 정상 작동 |
| TC-04 | **공백/빈 입력값 예외 처리 테스트** | 경고 Alert("Please enter a valid English sentence...")가 뜨며 쉐이크 효과와 함께 요청 차단 | **PASS** | alert 정상 출력 및 텍스트 박스 흔들림(shake) 애니메이션 작동 |
| TC-05 | **최소 글자수(2자 미만) 차단 테스트** | 1글자 입력 시 Alert 발생하며 요청 차단 | **PASS** | alert 정상 출력 및 텍스트 박스 흔들림(shake) 애니메이션 작동 |
| TC-06 | **최대 글자수(500자) 제어 테스트** | 500자 초과 텍스트 입력 방지 | **PASS** | textarea의 `maxlength="500"` 스펙에 의해 입력 강제 제한 작동 |

| TC-08 | **LocalStorage 영구 저장 테스트** | 분석 후 새로고침 시 히스토리에 기존 데이터가 유지되어 렌더링됨 | **PASS** | 로컬스토리지 복원으로 최근 내역 온전히 렌더링 확인 |

| TC-10 | **CDN 라이브러리 오류 핸들링** | CDN 로드 실패 시 "감정 분석 엔진을 불러오는 중..." 배너 활성화 및 버튼 잠금 | **PASS** | Sentiment 클래스 미정의 상태일 때 런타임 에러 없이 비활성화 작동 |

## 🐛 미결 이슈 및 버그 리스트 (Known Issues)
1. **이슈 내용**: 한국어 문장 입력 시 한국어 형태소 미지원으로 무조건 Neutral(0점) 판별되는 제약 사항.
   - **대처**: 이는 Sentiment.js 라이브러리의 원천적인 한계로 파악되어, UI 헤더 하단에 명확하게 `Supports English text analysis only` 경고 문구를 배치함으로써 UX 관점에서 예외 상황을 조율하였습니다.

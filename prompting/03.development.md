# 🚀 [03. 기능 구현 및 개발 진행 프롬프트]

이 프롬프트는 확정된 **PRD (docs/prd/PRD_example.md)**와 **TRD (docs/trd/TRD_example.md)**를 토대로 실제 소스 코드를 구현할 때 사용합니다.

---

## 📝 프롬프트 템플릿
아래 내용을 복사하여 AI 코딩 어시스턴트에게 붙여넣으세요.

```markdown
너는 풀스택 소프트웨어 엔지니어(Software Engineer)야.
확정된 PRD(docs/prd/PRD_example.md)와 TRD(docs/trd/TRD_example.md)를 완벽하게 숙지하고, 이에 맞게 실제 제품 코드 개발을 진행해보자.

### [개발 요구사항]
1. `docs/prd/PRD_example.md`와 `docs/trd/TRD_example.md`를 바탕으로 프로젝트의 코드 파일들을 생성/수정해줘.
2. TRD에 정의된 디렉터리 및 파일 구조(예: `index.html`, `style.css`, `script.js` 등)를 철저히 지키며 개발해줘.
3. 코드를 구현할 때는 아래의 모범 사례들을 준수해줘:
   - 클린 코드 작성 (Clean Code) 및 적절한 주석 추가
   - 에러 및 예외 케이스 처리 (빈 입력 방지 등)
   - 모바일 대응 반응형 디자인 적용
4. 개발 진행 사항과 추가되거나 변경된 구현 사항은 `report/03.dev_report.md`에 개발 진행 리포트로 요약 기록해줘.
5. 개발 중 발생한 특이사항이나 변경이 불가피한 기획/기술 스펙이 있다면 개발을 즉시 멈추고 나에게 먼저 의논해줘.
6. 개발 완료 후 `README.md` 현황판의 진행 상태를 업데이트해줘.

준비되었으면 개발 환경 및 폴더 구성을 먼저 파악한 후, 첫 단계인 기본 구조(HTML/CSS) 생성 계획을 알려주고 작업을 시작해줘.
```

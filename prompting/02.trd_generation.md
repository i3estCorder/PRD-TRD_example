# 🚀 [02. TRD 설계 및 검토 프롬프트]

이 프롬프트는 확정된 **PRD (docs/prd/PRD_example.md)**를 기술적으로 분석하여 구체적인 **TRD (기술 요구사항 정의서)**를 작성할 때 사용합니다.

---

## 📝 프롬프트 템플릿
아래 내용을 복사하여 AI 코딩 어시스턴트에게 붙여넣으세요.

```markdown
너는 수석 소프트웨어 아키텍트(Software Architect)이자 테크 리드(Tech Lead)야.
확정된 PRD(docs/prd/PRD_example.md) 문서를 읽고, 이를 바탕으로 구체적이고 정교한 TRD(Technical Requirement Document, 기술 요구사항 정의서)를 빌드해보자.

### [작업 요구사항]
1. `docs/prd/PRD_example.md` 파일을 먼저 분석해줘.
2. 기획 요구사항을 완벽하게 만족시키기 위해 다음 항목들을 포함한 기술 설계를 진행해줘:
   - 기술 스택 정의 및 선정 사유
   - 시스템 아키텍처 및 데이터 흐름도
   - 디렉터리 및 파일 구조
   - 컴포넌트 구조 및 각 모듈별 기능 상세
   - 데이터 모델 설계 (ERD 또는 상태 스키마)
   - 예외 처리(Exception Handling) 및 보안 요건
   - 성능 요구사항 및 배포 방식 (Vercel 등)
3. 기술 스택 선정 및 아키텍처 설계에 대해 다른 제안이나 대안(Trade-off)이 있다면 나에게 먼저 의견을 물어봐줘.
4. 아키텍처 설계와 기술 검토가 합의되면 `docs/trd/TRD_example.md`에 최종 기술 스펙을 저장하고, 작성 결과와 합의 사항을 `report/02.trd_report.md`에 기록해줘.
5. 모든 상태 변경은 `README.md` 현황판에 반영해줘.

준비되었으면 먼저 PRD를 분석하고, 최적의 아키텍처 제안 또는 필요한 기술적 논의 질문을 해줘.
```

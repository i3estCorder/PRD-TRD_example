# 🚀 [01. PRD 작성 및 검토 프롬프트]

이 프롬프트는 구현하고자 하는 서비스/기능의 아이디어를 기반으로 **PRD (제품 요구사항 정의서)**를 작성하거나 기존 PRD를 구체화할 때 사용합니다.

---

## 📝 프롬프트 템플릿
아래 내용을 복사하여 AI 코딩 어시스턴트에게 붙여넣으세요.

```markdown
너는 고도로 숙련된 PM(Product Manager)이야.
내가 구상하고 있는 서비스/기능에 대해 완벽한 PRD(Product Requirement Document, 제품 요구사항 정의서)를 단계별로 같이 작성해보자.

### [내가 구상 중인 아이디어 / 기존 기획 정보]
(여기에 기획하고 싶은 내용이나 기존 문서를 입력하세요. 예: "감정 분석 웹 서비스 만들기")

### [요구사항 및 가이드라인]
1. 위 아이디어를 바탕으로 아래 표준 PRD 목차에 맞춰 기획 문서를 작성해줘.
   - 제품 개요 (Product Overview)
   - 목표 (Goals & Non-Goals)
   - 핵심 기능 MVP (Functional Requirements)
   - 사용자 흐름 (User Journey & Flow)
   - UI/UX 설계 요건 (UI Requirements)
   - 비기능적 요구사항 (성능, 배포 등)
   - MVP 제외 범위 (Out of Scope)
   - 성공 지표 (Success Metrics)
2. 작성 과정에서 기획이 모호하거나 예외 케이스(Edge Case) 처리가 필요한 부분은 나에게 질문을 던져서 명확히 다듬어줘.
3. 최종 기획안이 확정되면, 프로젝트 루트에 있는 `docs/prd/PRD_example.md` 형식에 맞춰 저장하고, 검토 결과를 `report/01.prd_report.md`에 요약 정리해줘.
4. 모든 상태 변경은 `README.md` 현황판에 반영해줘.

준비되었으면 먼저 내가 작성한 아이디어를 분석하고 추가로 논의해야 할 질문 리스트를 보내줘.
```

# 🚀 [04. 테스트 및 검증 프롬프트]

이 프롬프트는 구현된 결과물이 **PRD (docs/prd/PRD_example.md)** 및 **TRD (docs/trd/TRD_example.md)**에 명시된 기능적/비기능적 요구사항을 올바르게 충족하는지 검증할 때 사용합니다.

---

## 📝 프롬프트 템플릿
아래 내용을 복사하여 AI 코딩 어시스턴트에게 붙여넣으세요.

```markdown
너는 전문 QA 엔지니어(Quality Assurance Engineer)야.
구현된 웹 앱의 소스 코드를 면밀히 분석하고, PRD 및 TRD의 성공 기준에 부합하는지 기능 검증과 테스트를 수행하자.

### [검증 및 테스트 요구사항]
1. `docs/prd/PRD_example.md`의 기능 요구사항과 `docs/trd/TRD_example.md`의 성능/보안/예외 처리 기준을 기반으로 테스트 시나리오를 설계해줘.
2. 테스트 시나리오에는 최소한 다음 케이스가 포함되어야 해:
   - 정상적인 문장 입력 시 감정 분석 및 추천 답변 출력 테스트 (Positive, Negative, Neutral 케이스 확인)
   - 공백 또는 빈 문자열 입력 시 예외 처리(Alert 발생 등) 작동 테스트
   - 모바일 기기 크기에서의 반응형 레이아웃 정상 동작 확인
3. 직접 테스트를 실행하거나 브라우저 검증 도구를 사용해보고, 테스트 시나리오별 패스/실패 여부를 `report/04.verify_report.md`에 테스트 결과서로 작성해줘.
4. 발견된 버그가 있다면 해결 방안과 함께 리포트에 기록해주고 나에게 알려줘.
5. 검증 완료 후 `README.md` 현황판의 테스트 단계를 완료 상태로 업데이트해줘.

준비되었으면 먼저 수행할 테스트 시나리오 목록을 알려줘.
```
